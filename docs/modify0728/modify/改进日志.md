## 一、`modify/app.py` — 预测模型改进

### 1. ARIMA 参数自动搜索 + d>0 差分

#### 改动内容

| 项目 | 改动前 | 改动后 |
|------|--------|--------|
| 差分阶数 `d` | 硬编码 `0`（不做差分） | 由 `adfuller` 平稳性检验自动确定，最多 `max_d=2` |
| ARIMA 阶数 `(p,d,q)` | 固定 `(3,0,0)` | 网格搜索 `(p≤5, d=auto, q≤5)`，以 AIC 为准则 |
| 搜索空间 | 无 | `p∈[0,5]`，`d∈[0,2]`，`q∈[0,5]` |

#### 新增方法

**`_find_optimal_d(price)`**
- 通过 `adfuller` 检验递归确定差分阶数
- 若序列不平稳则做一阶差分，最多重复 `max_d` 次
- 保证 ARIMA 输入为平稳序列，避免虚假回归

**`_find_best_arima_order(price)`**
- 在 `(p≤5, d=auto, q≤5)` 范围内网格搜索
- 以 `AIC`（默认）或 `BIC` 为准则选最优阶数
- 打印搜索过程和最优结果

### 2. XGBoost 超参数 RandomizedSearchCV 调优

#### 改动内容

| 项目 | 改动前 | 改动后 |
|------|--------|--------|
| 搜索方法 | `GridSearchCV`（全量网格，3折CV） | `RandomizedSearchCV`（50次随机搜索，5折CV） |
| 搜索空间 | 较小 | 更广（含 gamma/reg_alpha/reg_lambda） |
| lags | 固定 `3` | 扩展至 `5`（硫磺价格传导周期） |

#### RandomizedSearchCV 搜索空间

```python
n_estimators:     [50, 100, 150, 200, 250, 300]
max_depth:        [2, 3, 4, 5, 6, 7]
learning_rate:    [0.01, 0.03, 0.05, 0.08, 0.1, 0.15]
min_child_weight: [1, 3, 5, 7]
subsample:        [0.6, 0.7, 0.8, 0.9, 1.0]
colsample_bytree: [0.6, 0.7, 0.8, 0.9, 1.0]
gamma:            [0, 0.1, 0.2, 0.3]
reg_alpha:        [0, 0.01, 0.1]
reg_lambda:       [1, 1.5, 2]
```

### 4. 特征工程：`_build_features()`

#### 新增多因子差分特征

| 特征类型 | 特征名 | 说明 |
|----------|--------|------|
| 残差滞后 | `resid_lag_1` ~ `resid_lag_5` | ARIMA 残差 5 阶滞后 |
| WTI 差分 | `wti_diff_lag_1` | WTI 价格一阶差分 |
| 天然气差分 | `gas_diff_lag_1` | 天然气价格一阶差分 |
| 磷酸差分 | `phosphate_diff_lag_1` | 磷酸价格一阶差分 |
| 钾肥差分 | `potash_diff_lag_1` | 氯化钾价格一阶差分 |
| 尿素差分 | `urea_diff_lag_1` | 尿素价格一阶差分 |
| BDI 差分 | `bdi_diff_lag_1` | 波罗的海指数一阶差分 |
| 季度哑变量 | `Q1, Q2, Q3` | Q4 为基准组 |
| 月份傅里叶 | `month_sin, month_cos` | 12个月周期三角函数 |

> **设计原则**：所有外部因子使用差分而非原始值，消除量纲影响，让模型学习因子变化趋势而非绝对值。

### 5. 两阶段训练：`fine_tune()`

#### 方法签名

```python
def fine_tune(learning_rate=0.01, n_estimators=50, min_commodity_rows=30) -> dict
```

#### 两阶段策略

| 阶段 | 数据范围 | 学习率 | 目的 |
|------|---------|--------|------|
| Stage 1 预训练 | 全量数据（品种因子=0） | 0.1 | 学到残差滞后模式 |
| Stage 2 微调 | 品种因子对齐窗口 | 0.01 | 注入品种因子信号 |

- Stage 2 在品种因子可用的时间窗口（通常最近 90~166 天）上继续训练
- 使用小学习率避免遗忘预训练知识

## 二、`modify/test.py` — 对比测试脚本

### 重写目的

将测试脚本从"A/B 外部因子对比"改为"新旧两版模型效果对比"，在同一数据、同一划分下量化改进幅度。

### 对比设计

| 对比维度 | A组（python-service 旧版） | B组（modify 新版） |
|----------|---------------------------|-------------------|
| ARIMA 阶数 | 固定 `(0,1,1)` | 自研网格搜索 `(p,d,q)` |
| XGBoost 参数 | 默认固定 | RandomizedSearchCV 最优 |
| lags | 3 | 5 |
| 特征 | 简化残差滞后 | 多因子差分特征 + 季节性 |
| 数据划分 | 完全相同 | 完全相同 |

### 输出内容

1. **数据概况** — 加载条数、时间范围、训练/测试集划分
2. **A组详细指标** — MAPE / MAE / R² / ARIMA阶数 / XGBoost参数
3. **B组详细指标** — MAPE / MAE / R² / ARIMA阶数（自动搜索结果）/ XGBoost参数（随机搜索结果）/ CV最佳MAE
4. **A vs B 改善幅度汇总表** — 六项指标并列对比
5. **结论** — ✅全面优于 / ⚠️略优 / ⚠️旧版具竞争力

### 特征维度不匹配 Bug 修复（2026-07-28）

#### 问题现象

运行对比测试时报错：
```
ValueError: Feature shape mismatch, expected: 12, got 16
```

- A组 OldPredictor 训练阶段 features shape=(787, 12)
- 预测阶段 input_vec 生成 16 维特征，维度不匹配

#### 根本原因

训练阶段和预测阶段**特征构造代码重复编写、逻辑不一致**：

- **训练时**：OldPredictor 用 `else` 分支的简单残差滞后（12维：resid_lag×3 + wti_diff + gas_diff + 季节性 5 维 + phosphate/potash/urea/bdi 差分 4 维 = 12维）
- **预测时**：`_build_xgb_input_vec` 用 `lags >= 5` 判断走新版路径（16维），而非复现训练时的特征工程逻辑

#### 修复方案

1. **抽取公共特征构造函数**：`_build_xgb_input_vec` 不再重复写预测特征逻辑，而是**调用 `predictor._build_features` 复现训练时的特征工程**
2. **传入训练数据切片**：`data.iloc[:split_index]` 确保预测时用的是与训练时完全相同的索引对齐方式
3. **索引对齐**：`fake_resid` 的 index 与 `train_data` 对齐，保证 `dropna()` 行为一致

```python
# 修复后的核心逻辑
def _build_xgb_input_vec(predictor, last_known_resid, train_data, lags):
    if hasattr(predictor, '_build_features'):
        fake_resid = pd.Series(0.0, index=train_data.index)
        fake_resid.iloc[-lags:] = last_known_resid
        features, _ = predictor._build_features(fake_resid, wti_s, gas_s, train_data, lags)
        vec = features.iloc[-1].values  # 取最后一行（预测时刻输入）
        return vec.reshape(1, -1)
    else:
        # 纯旧版：仅残差滞后
        return np.array(list(last_known_resid)).reshape(1, -1)
```

#### 同步修复：ARIMA/XGBoost 搜索空间过大导致过拟合

| 参数 | 修改前 | 修改后 | 原因 |
|------|--------|--------|------|
| ARIMA 搜索空间 | `p≤5, d≤2, q≤5` | `p≤3, d≤1, q≤3` | 防止在训练集上过拟合 |
| XGBoost 搜索空间 | 6 个 n_estimators 等 | 缩减至 3~4 个选项 | 避免统计噪声干扰 |
| RandomizedSearchCV 迭代 | 50 次 | 20 次 | 减少过拟合风险 |
| 品种因子特征 | 无条件加入 | 仅在 `diff.std() > 0` 时加入 | 避免全 0 常量特征干扰 |
| 测试集比例 | 10% | 20% | 增加验证样本量 |

### 指标对比

| 指标 | A组(旧版) | B组(新版) | 改善幅度 |
|------|-----------|-----------|---------|
| MAPE | 8.96% | 8.94% | +0.3% |
| MAE | 19.5134 | 19.4630 | +0.3% |
| R² | -0.8651 | -0.8592 | +0.0059 |
| ARIMA 阶数 | (2, 1, 2) | (2, 1, 2) | 相同（巧合） |
| XGB n_estimators | 100 | 50 | 更精简 |
| XGB max_depth | 3 | 3 | 相同 |

### 分析

- **R² 为负值**：说明预测效果较差，模型还有很大改进空间
- **新版略优但差异小**：两版 ARIMA 阶数恰好相同（均为 2,1,2），说明在这个数据集上自动搜索找到了相同阶数
- **主要差距来源**：XGBoost 从默认参数 100 棵树 → 随机搜索最优 50 棵树，计算量减少一半且效果相当
- **改进方向建议**：
  1. 引入更多有效外部因子（如真实磷酸/钾肥/尿素价格而非模拟数据）
  2. 尝试 Transformer/LSTM 等序列模型
  3. 增大训练数据量或使用更多历史数据进行预训练
