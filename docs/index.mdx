# 硫磺采购决策系统

为企业提供硫磺市场价格预测、趋势分析和采购决策辅助。

## 核心能力

- **价格预测** — Hybrid ARIMA + XGBoost 多模型集成预测
- **库存分析** — 港口库存监控与环比变化分析
- **企业决策** — 基于影响因子权重的个性化采购建议
- **AI 对话** — 基于 DeepSeek 的市场分析助手
- **知识图谱** — Neo4j 双层知识图谱（宏观 + 企业）推理
- **外部数据** — EIA / FRED / GDELT / 生意社多源数据接入
