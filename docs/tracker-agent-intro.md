# Tracker Agent 项目介绍

> 一句话定位：**自动帮你盯行情、发现异常、推送预警、生成报告的智能助手**

---

## 这个项目是什么？

想象一下这样的场景：

- 你是硫磺采购员，每天要盯着价格走势、港口库存、行业新闻
- 信息来源分散（网站、公众号、行业群），每天花大量时间收集整理
- 价格突然大涨，你却晚了一小时才知道，错过了最佳采购时机
- 需要写周报月报，数据整理费时费力

**Tracker Agent 就是为了解决这些问题而设计的。**

它能做到：
- **自动追踪**：定时采集价格、库存、新闻数据，不用你手动查
- **智能预警**：价格超过阈值、库存降到危险线，第一时间推送通知
- **自动报告**：每天早上收到市场简报，每周收到趋势分析
- **决策建议**：结合你家企业的库存情况，给出个性化采购建议

**举个例子**：

```
用户订阅："硫磺价格超过1000元/吨时提醒我"

3. 立刻推送通知：邮件 + Web弹窗
4. 同时附上分析：为什么涨？建议怎么办？
```

## 能追踪哪些行业？

**初期聚焦硫磺化工**，但架构设计支持快速扩展：

| 行业 | 数据来源 | 接入难度 |
|------|----------|----------|
|硫磺化工 | 已有API（EIA/FRED/GDELT） | ✅ 已完成 |
| 药材中药 | 药材价格网、产地库存 | 1-2天 |
| 石油原油 | 复用EIA + 原油API | 1-2天 |
| 黄金期货 | 期货交易所API | 1-2天 |

**核心设计**：底层逻辑不变，只需替换数据源，就能快速适配新行业。

## 用户怎么使用？

### 方式一：Web网页

- 登录后配置订阅：选择追踪品类、设置预警阈值、选择通知渠道
- 每天收到邮件简报
- 异动时收到Web推送或短信

### 方式二：Claude Desktop（未来）

- 在 Claude 桌面版直接对话："帮我追踪硫磺价格，超过1000提醒"
- Claude 会自动调用 Tracker Agent 的工具完成订阅

## 技术架构简述

```
用户 → Tracker Agent（调度+检测+生成）→ API Server（数据+预测+决策）→ 数据库
                                   ↓
                              通知推送（邮件/Web/SMS）
```

**关键点**：
- Tracker Agent 调用现有 API Server 的端点获取数据
- 不重复造轮子，复用已有的价格预测、决策建议功能
- 新增的核心是：定时调度、异动检测、订阅管理

## 一句话总结

**Tracker Agent = 自动行情盯盘 + 智能异动预警 + 自动报告生成**

- 解决采购人员信息收集费时、反应滞后、报告难写的痛点
- 支持多行业扩展，一套架构快速适配新赛道
- 双入口：Web网页 + Claude Desktop
