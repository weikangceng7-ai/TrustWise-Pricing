# Sulfur Agent MCP Server v0.3 —— 重磅升级

> **一句话总结**: v0.3 将 MCP Server 从"单品种硫磺数据查询工具"升级为"多品种大宗原料智能决策平台"，新增 7 个工具，覆盖多品种对比、深度学习预测、模型精度评估和客户成功案例四大场景。

---

## 一、v0.3 新增了什么？（5 分钟看懂）

### 📦 新增 1：多品种大宗原料支持

**以前**：只能查硫磺价格。

**现在**：硫磺、磷矿、钾肥、尿素 **4 大品种**全覆盖。

这意味着什么？如果你的企业同时采购硫磺和钾肥，以前需要分别手动查数据拼结论，现在 MCP Server 一个工具就能给你答案。

```
你问："现在磷矿和尿素的行情怎么样？"
AI 答：
  📈 磷矿：¥1,080/吨，+1.5%，趋势平稳
  📉 尿素：¥2,350/吨，-2.1%，走势偏弱
  两品种相关性：弱（r=0.05），建议分开决策
```

**核心工具**：
- `list_commodities` — 一网打尽所有品种的行情概览
- `get_commodity_analysis` — 深入单个品种，看驱动因素、相关性、市场展望
- `cross_commodity_analysis` — 品种间横向对比 + 协同采购建议

---

### 🧠 新增 2：Transformer 深度学习预测

**以前**：只有 ARIMA + XGBoost 传统模型预测。

**现在**：新增 **PatchTST Transformer 模型** + **双模型加权融合预测**。

把两个模型比作人的话：
- **ARIMA + XGBoost** = 经验丰富的老分析师，擅长看线性趋势
- **Transformer (PatchTST)** = 数学天才新人，擅长发现隐藏的非线性规律

两个模型各取所长，融合后的预测比单一模型**更稳、更准**。

```
你问："未来两周硫磺价格会怎么走？"
AI 答：
  🔬 双模型融合预测报告
  ARIMA+XGBoost (60%) + Transformer/PatchTST (40%)
  价格区间：¥1,820 ~ ¥1,910 /吨
  趋势：📈 稳步上涨
```

**核心工具**：
- `predict_with_transformer` — 纯 Transformer 模型预测，看"新角度看价格"
- `get_combined_prediction` — 双剑合璧，融合预测结果

---

### 📊 新增 3：模型精度看板

**以前**：不知道模型准不准，只能"凭感觉"信任。

**现在**：MAPE、MAE、RMSE、R² 四大指标全透明，还能按企业看精度分布。

> 就像买了理财产品能看到历史收益率一样 —— 模型准不准，数据说了算。

```
你问："你们的预测模型靠谱吗？"
AI 答：
  📊 模型精度评估报告
  MAPE: 2.1% 🟢 优秀  （行业标准 <5% 即合格）
  R²: 0.954 🟢 优秀   （越接近 1 越准）
  总预测次数：365 次

  各企业精度：
  ⭐ 湖北宜化：MAPE 3.2%
  ✅ 鲁西化工：MAPE 3.8%
  ✅ 金正大：  MAPE 4.1%
```

**核心工具**：
- `get_accuracy_metrics` — 查看模型精度核心指标

---

### 🏆 新增 4：客户成功案例

**以前**：只能在官网看静态案例。

**现在**：AI 可以随时调取真实客户案例数据，用实际数字说话。

> 当客户问"你们有没有类似我们公司的案例？"，AI 直接调出匹配行业的最佳实践。

```
你问："有没有化肥企业用你们的案例？"
AI 答：
  🏆 鲁西化工集团（化肥制造）
  分析效率提升：70%
  人力节省：3人
  预警提前量：48小时
  报告生成时间：3天 → 10分钟
```

**核心工具**：
- `get_success_cases` — 按行业筛选客户成功案例

## 三、为什么这次升级对你很重要？

### 如果你是采购经理

以前 AI 只能告诉你"硫磺价格涨了"，现在能告诉你：

- "硫磺和磷矿高度联动（r=0.82），建议同步备货"
- "钾肥受地缘政治影响独立性强，应单独建立 45-60 天安全库存"
- "基于双模型融合预测，未来两周硫磺价格大概率震荡上行，建议本周完成采购"

**一句话：从"知道价格"到"知道怎么买"。**

### 如果你是销售 / 售前

以前给客户演示，你需要手动准备案例数据和竞品对比。

现在直接问 AI：
- "有没有类似金正大的客户案例？"
- "我们的模型精度怎么样？"
- "硫磺和磷矿的关联性如何？"

**一句话：AI 变身随身售前顾问，数据张口就来。**

### 如果你是开发者

以前 MCP Server = 硫磺数据查询工具。

现在 MCP Server = 大宗原料多品种智能决策平台的基础设施。

新增的 Transformer 预测和融合预测能力，让 MCP 端也具备了和 Web 端同等的 AI 决策能力。

**一句话：API 能力对齐产品能力，SDK 生态就绪。**

## 四、快速体验

### 升级方式（零停机）

如果你已经在用 v0.2，只需要：

```bash
# 拉取最新代码
git pull

# 重新编译
cd mcp-server
npm run build

# 重启服务
npm run mcp:http
```

如果通过 Docker / Railway 部署，重新构建镜像即可自动拉取最新代码。

### DEMO 模式一键体验

```bash
DEMO_MODE=true MCP_TRANSPORT=http npm run mcp:http
```

无需 API Key，所有新工具返回模拟数据供你尝鲜。
