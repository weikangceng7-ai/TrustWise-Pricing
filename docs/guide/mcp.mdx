# MCP 接入指南

**MCP（Model Context Protocol）** 是一种标准协议，让 AI 客户端能够调用外部工具获取实时数据。本系统提供独立的 MCP Server，接入后可在 Claude Desktop 中直接提问，AI 会自动调用系统数据回答。

<Info>
本页在线地址：**https://weikang.mintlify.app/guide/mcp**（文档站首页：https://weikang.mintlify.app）
</Info>

<Info>MCP Server 是独立的 Node.js 程序（位于仓库 `mcp-server/` 目录），通过 API Key 调用主后端接口。</Info>

## 架构

```
AI 客户端（Claude Desktop / DeepSeek 等）
        ↓ stdio 或 HTTP
   MCP Server（Node.js，默认监听 3100 端口）
        ↓ 带 API Key 调用
   主后端（https://sulfur-agent-web.vercel.app）
```

## 快速开始

### 1. 编译 MCP Server

```bash
cd mcp-server
npm install
npm run build
```

编译成功后生成 `dist/index.js`。

### 2. 环境变量

推荐使用 `.env` 文件管理环境变量（支持 CMD / PowerShell / bash 所有终端）：

```bash
# 复制示例文件
cp .env.example .env
# 编辑 .env，填入你的 API_KEY
```

| 变量名 | 说明 | 示例 |
|--------|------|------|
| `API_BASE_URL` | 主后端地址 | `https://sulfur-agent-web.vercel.app` |
| `API_KEY` | API 密钥（在线平台登录后获取） | `sk_xxxxxx` |
| `INDUSTRY_CODE` | 行业代码 | `sulfur` |
| `MCP_TRANSPORT` | 传输模式：`stdio` / `http` | `stdio` |
| `MCP_PORT` | HTTP 模式监听端口 | `3100` |

<Info>`.env` 文件中的变量仅在系统环境变量未设置时生效，系统环境变量优先级更高。</Info>

API Key 的获取方式见 [认证方式](/guide/authentication)。

## 接入方式：Claude Desktop（stdio 模式）

<Steps>
  <Step title="编译 MCP Server">
    确认已完成上文"快速开始"中的编译，`mcp-server/dist/index.js` 文件存在。
  </Step>
  <Step title="打开 Claude Desktop 配置文件">
    Claude Desktop → **Settings**（设置）→ **Developer**（开发者）→ **Edit Config**（编辑配置），会打开 `claude_desktop_config.json`。
  </Step>
  <Step title="添加 MCP Server 配置">
    在配置文件中添加以下内容（替换为你的实际路径和 API Key）：

    ```json
    {
      "mcpServers": {
        "sulfur-tracker-agent": {
          "command": "node",
          "args": ["<仓库绝对路径>/mcp-server/dist/index.js"],
          "env": {
            "API_BASE_URL": "https://sulfur-agent-web.vercel.app",
            "API_KEY": "sk_你的API_KEY",
            "INDUSTRY_CODE": "sulfur"
          }
        }
      }
    }
    ```

    <Warning>Windows 路径中反斜杠必须双写（`\\`），且需为绝对路径。JSON 最后一个对象后面不能有逗号。</Warning>
  </Step>
  <Step title="重启 Claude Desktop">
    保存配置后，**完全退出** Claude Desktop 并重新打开（不是最小化，是退出进程）。
  </Step>
  <Step title="验证接入">
    重启后在对话输入框附近可看到工具图标（锤子/扳手），点击可见 `sulfur-tracker-agent` 的 18 个工具。直接提问测试：

    ```
    最近硫磺价格走势怎么样？
    ```

    Claude 会自动调用 MCP 工具获取真实数据后回复。
  </Step>
</Steps>

## 可选：HTTP 模式（公网部署）

除本地 stdio 模式外，MCP Server 也可以以 HTTP 模式部署到公网，供支持 HTTP 传输的 MCP 客户端远程连接。

### 本地启动

在 `.env` 中设置 `MCP_TRANSPORT=http`，然后：

```bash
npm run dev
```

访问 `http://localhost:3100/health` 返回 `{"status":"ok"}` 即启动成功，MCP 端点为 `http://localhost:3100/mcp`。

### Docker / Railway 部署

仓库已内置 `mcp-server/Dockerfile` 和 `railway.json`：

1. 在 [Railway](https://railway.app/) 新建项目，选择 **Deploy from GitHub repo**；
2. 在 Variables 面板配置上表中的环境变量（`MCP_TRANSPORT` 设为 `http`）；
3. 开启 Public Networking，部署完成后 MCP 端点为 `https://<你的域名>/mcp`。

## 常见问题

<AccordionGroup>
  <Accordion title="Claude Desktop 中没有显示工具图标">
    依次检查：`dist/index.js` 是否存在（重新 `npm run build`）、配置中路径是否为绝对路径且反斜杠双写、JSON 是否有语法错误，最后完全退出并重启 Claude Desktop。
  </Accordion>
  <Accordion title="工具调用报错 fetch failed 或 API Key 无效">
    确认 `API_KEY` 无多余空格、`API_BASE_URL` 正确。若后端正在部署或维护，稍后重试。
  </Accordion>
  <Accordion title="工具返回数据为空">
    说明后端数据库中暂无对应数据，可换用其他工具验证连通性，如查询港口库存或市场新闻。
  </Accordion>
  <Accordion title="如何查看调用日志">
    Claude Desktop → Settings → Developer → View MCP Server Logs。
  </Accordion>
</AccordionGroup>
