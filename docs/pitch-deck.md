## 1. 执行摘要 (Executive Summary)

**SulfurAI** 是中国首个面向化工行业的大宗原料采购智能决策平台。通过 **双引擎 AI 架构**（传统 ML 时间序列预测 + LLM Agent 知识推理），帮助磷肥及化工企业在硫磺采购中实现 **8-15% 的成本降低** 和 **70% 的分析效率提升**。

**一句话**: 我们用 AI 帮化工企业买得更便宜、买得更聪明。

**核心数据**:
- 95%+ 价格预测准确率
- 100+ 企业用户
- 10+ 年历史数据覆盖
- 千亿级目标市场

## 2. 市场机会 (Market Opportunity)

### 硫磺市场画像

| 指标 | 数据 |
|------|------|
| 中国年硫磺进口量 | 1,000+ 万吨 |
| 全球硫磺市场规模 | ~$150 亿美元 |
| 中国磷肥年产量 | 1,500+ 万吨 |
| 硫磺占磷肥成本比 | 40-50% |
| 单企业年采购额 | 10-50 亿元 |

### 痛点

1. **价格波动剧烈**: 硫磺价格受国际油价、运费、地缘政治、季节性需求等多因素影响，周波动可达 5-10%
2. **决策依赖经验**: 采购决策高度依赖"老师傅"经验，缺少数据支撑
3. **信息碎片化**: 需要同时关注港口库存、国际报价、下游开工率、运费等数十个数据源
4. **错失窗口期**: 采购时机判断失误，单次可能导致数百万甚至千万级损失

### 为什么是现在？

- 中国 "双碳" 政策推动化工行业数字化转型
- 磷肥行业集中度提升，头部企业对数据驱动决策需求迫切
- LLM 技术成熟，使领域知识推理成为可能
- 国产替代趋势下，工业软件赛道资本热捧

## 3. 产品概述 (Product Demo Flow)

### Demo 路径 (5 分钟)

```
首页 Landing → 仪表盘 Dashboard → 价格预测 → Agent 对话 → 采购报告
```

### 四大核心模块

| 模块 | 功能 | 技术 |
|------|------|------|
| **智能价格预测** | 短期/中期硫磺价格预测，置信区间 | Hybrid ARIMA + XGBoost |
| **AI 决策助手** | 对话式采购建议，市场分析，风险评估 | LLM Agent (DeepSeek/Qwen) |
| **知识图谱引擎** | 价格-供需-政策因果推理，企业个性化分析 | Neo4j 双层知识图谱 |
| **自动化报告** | 一键生成专业采购决策报告 (Word/PDF) | AI 结构化输出 |

### 技术架构

```
外部数据源 (EIA/FRED/GDELT/AkShare)
        ↓
数据采集层 (Cron + Feeds)
        ↓
├─ 宏观预测引擎 (Python: ARIMA + XGBoost)
└─ 企业决策引擎 (LLM Agent + Neo4j KG)
        ↓
业务 API 层 (Hono + Next.js Route Handlers)
        ↓
展示层 (Next.js 16 + React 19 + Recharts)
```

## 4. 技术壁垒 (Technology Moat)

### 4.1 双重预测引擎

| 引擎 | 方法 | 用途 |
|------|------|------|
| 宏观分析引擎 | Hybrid ARIMA + XGBoost 混合模型 | 时序价格预测，趋势分析 |
| 企业决策引擎 | LLM Agent + 知识图谱推理 | 个性化采购建议，风险预警 |

**差异化**: 不是单一的 ML 模型或 ChatGPT wrapper，而是**结构化预测 + 非结构化推理**的混合系统。

### 4.2 双层知识图谱 (Neo4j)

- **第一层 (宏观)**: 价格影响因子关系网络、产业链结构、市场动态事件
- **第二层 (企业)**: 企业个性化参数、影响因子权重矩阵、历史决策记录

知识图谱使得系统能从 "硫磺价格上涨" 推理出 "企业A建议本周采购 5000 吨"，中间经过多层因果关系链。

### 4.3 行业 Know-How 沉淀

- 120+ 影响因子的权重矩阵
- 80+ 条领域规则引擎
- 10+ 年历史价格数据库 schema
- 3 类典型企业决策模型模板

### 4.4 技术栈优势

- **Next.js 16 + React 19**: 现代前端架构，Vercel 部署
- **Drizzle ORM + PostgreSQL**: 类型安全的数据层
- **AI SDK 6 + OpenRouter**: 多模型 LLM 集成
- **MCP Server**: 支持 AI Agent 生态集成
