# 市场分析页面使用指南

> 一句话定位：**把「Tracker 追踪」「品种对比」「模型精度」三个功能收进一个页面，一站式完成市场分析。**

---

## 怎么进入？

| 方式 | 操作 |
|------|------|
| 侧边栏 | 功能模块 → **市场分析** |
| 仪表盘 | 点击「品种覆盖」或「模型精度」卡片，直达对应 Tab |
| 直接输网址 | `/market-analysis?tab=tracker` / `?tab=commodities` / `?tab=accuracy` |
| 旧链接 | `/tracker`、`/commodities`、`/accuracy` 自动跳转到对应 Tab，收藏夹不用改 |

切换 Tab 时网址会同步更新，把当前网址发给同事，对方打开就是同一个板块。

---

## 三个板块怎么用？

### 1. Tracker 追踪：让系统替你盯盘

**看什么：**
- 顶部四张状态卡：**活跃订阅数、未读异动数、最近执行时间、下次执行时间**
- 左侧「最近异动事件」：每条异动带紧急程度标签（高/中/低），点 ✓ 标记已读
- 右侧「活跃订阅」：当前正在运行的追踪任务一览

**做什么：**
1. 点击 **管理订阅 / 新建订阅**，进入订阅配置页，设定追踪条件（如"硫磺价格波动超过 3% 时提醒我"）
2. 回到本页点击 **立即执行所有追踪**，系统马上巡检一轮市场数据
3. 有异动时，事件会出现在列表里；点 **查看全部异动** 进入完整的异动事件列表

### 2. 品种对比：四大品种一屏看全

**看什么：**
- 顶部四张品种卡：**硫磺、磷矿、钾肥、尿素**的当前价格、涨跌幅、数据来源标签（真实 / 推算 / 模拟）、活跃度和风险提示
- 左侧「详细分析」：选中品种的价格、波动性、风险等级、关键驱动因素、市场展望
- 右侧「价格对比」条形图 + 「品种相关性」（如硫磺与磷矿强正相关 r=0.82，因为磷肥生产拉动硫磺需求）

**做什么：**
- 点击任意品种卡片，左侧详细分析随之切换
- 采购前先看相关性：关联品种在涨，往往预示目标品种的价格压力

### 3. 模型精度：预测到底准不准？

**看什么：**

| 指标 | 含义 | 怎么读 |
|------|------|--------|
| MAPE | 平均绝对百分比误差 | 越低越好，2% 左右属于优秀 |
| MAE | 平均绝对误差（元/吨） | 预测价和实际价平均差多少钱 |
| RMSE | 均方根误差 | 对大偏差更敏感，检验极端情况 |
| R² | 决定系数 | 越接近 1，模型解释力越强 |

- 「预测 vs 实际价格对比」图：虚线（预测）贴近实线（实际）说明模型可靠，阴影带是置信区间
- 「MAPE 趋势」图：近 12 周误差走势，持续走低说明模型在变好
- 「按企业精度分布」：每家接入企业各自的预测精度和评级

**做什么：**
- 采纳采购建议前，先来这里确认最近的预测误差水平，误差越低，建议参考价值越高
