# 硫磺价格预测模型改造报告

> 日期：2026-07-24

---

## 一、改造背景

原系统使用 Hybrid ARIMA + XGBoost 模型，其中 XGBoost 仅使用 3 个 lag 特征（lag_1、lag_2、lag_3），无外部因子接入。外部因子（硫磺基准价、磷矿石、钾肥、尿素、BDI）虽已写在代码中，但未引入模型。

---

## 二、改了什么

### 改动 1：ARIMA 参数优化

**原问题**：ARIMA(0,1,1) 的差分参数 d=1 使模型只能预测"保持上一期不变"（平线），而测试集价格从 170 上涨至 244，ARIMA 全程预测 185.3，完全踏空趋势。

```
ARIMA(0,1,1) 预测值：185.3 → 185.3 → 185.3 → 185.3（平线）
测试集实际值：    187.6 → 229.2 → 244.4（持续上涨）
```

**修复**：将 `arima_order` 从 `(0, 1, 1)` 改为 `(3, 0, 0)`

- `d=0`：不做差分，直接对原始价格建模
- `p=3`：用过去 3 个价格预测当前值，能追踪趋势惯性

### 改动 2：XGBoost 接入外部因子

**原问题**：外部因子 API 数据仅覆盖 2026 年，与训练集（2022-2025）时间不重叠，全部降级为 0，XGBoost 实际只有 3 个 lag 特征

**修复**：建立"优先 API，失败 Excel 兜底"机制：

| 因子 | 优先来源 | 兜底来源 | 数据量 |
|---|---|---|---|
| sulfur_spot | CommodityDataFetcher API | Sheet2 长江港硫磺历史价格 | 1884 条 |
| ccpi | — | Sheet1 列2 | 881 条 |
| exchange_rate | — | Sheet1 列4 | 881 条 |
| dxy | — | Sheet1 列5 | 881 条 |
| wti | — | Sheet1 列6 | 881 条 |
| natural_gas | — | Sheet1 列7 | 881 条 |

> phosphate、potash、urea、BDI 因 API 和 Excel 均无数据，已删除。

外部因子以 Z-Score 标准化后作为 XGBoost 的输入特征（t-1 时刻滞后值），与 3 个 lag 特征合并，共 9 个特征输入 XGBoost。

---

## 三、改完效果

**测试条件**：881 条真实历史价格（2022-01-04 → 2025-07-17），90% 训练 / 10% 测试

### 各方案对比

| 方案 | XGBoost 特征 | MAPE | MAE（元/吨） |
|---|---|---|---|
| 原方案 ARIMA(0,1,1) + XGBoost 3个lag | 3 | 8.81% | 19.20 |
| 调参后 ARIMA(3,0,0) + XGBoost 3个lag | 3 | 8.03% | 17.53 |
| **最终方案 ARIMA(3,0,0) + XGBoost 9个特征** | **9** | **7.69%** | **16.74** |

### 改善分解

| 改善来源 | MAPE 变化 |
|---|---|
| ARIMA 参数优化 (0,1,1) → (3,0,0) | -0.78pp |
| XGBoost 接入 6 个外部因子 | -0.34pp |
| **合计** | **-1.12pp** |
