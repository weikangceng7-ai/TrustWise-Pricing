## 详细版：五大更新（3 分钟讲稿）

### 1. 价格数据升级：从"模拟"到"真实行情"

**以前是什么样？**
系统早期用的是模拟价格数据，主要用于演示预测模型的能力。

**现在是什么样？**
- 数据获取器直连**生意社（100ppi.com）**等大宗商品行情网站，抓取真实现货报价；
- 硫磺价格不再是拍脑袋的模拟值，而是通过**尿素、甲醇等关联品种的真实价格，用加权模型推算**出来的——因为硫磺是化肥产业链的上游原料，它的价格和这些下游产品高度联动；
- 国内网络环境也做了适配，数据获取稳定可靠。

**对您意味着什么？**
您在系统里看到的每一条价格曲线、每一次预测，背后都有真实市场行情做支撑。**看得放心，用得踏实。**

---

### 2. Tracker 智能追踪：系统替您盯盘

**解决什么问题？**
采购负责人每天要盯价格、盯库存、盯新闻，人力盯盘费时费力，还容易漏掉关键变化。

**它是怎么工作的？**
1. **订阅**：您告诉系统关心什么——比如"硫磺价格波动超过 3% 时通知我"；
2. **巡检**：系统按小时/天/周自动检查市场数据，不休息、不遗漏；
3. **预警**：一旦触发您设定的条件，立刻推送预警到预警中心；
4. **报告**：定期自动生成追踪报告，市场发生了什么、有什么值得注意，一目了然。

**对您意味着什么？**
以前是"人找信息"，现在是"信息找人"。您的分析团队可以把时间从盯盘转向真正的决策。

**在哪里体验？**
系统新增了三个页面：追踪总览、预警中心、订阅管理。

---

### 3. 开放 API + MCP 服务：把能力接到您自己的系统里

**解决什么问题？**
很多客户有自己的 ERP、采购系统、数据中台，希望把我们的价格数据和预测结果直接用起来，而不是每次都要打开我们的网站看。

**这次开放了什么？**
- **REST API**：标准接口，覆盖价格查询、价格预测、企业数据、AI 对话等能力，带 API Key 认证和完善的调用文档；
- **API 控制台**：在网页上就能申请密钥、在线调试接口，开发人员上手快；
- **MCP 服务**：让 AI 助手直接调用我们的数据和预测能力（下面重点展开）。

**对您意味着什么？**
我们的系统不再是一个孤立的网站，而是**一套可以嵌入您现有工作流的数据和决策能力**。

### 3+. 重点展开：MCP 服务——让您的 AI 助手变成硫磺行情专家

#### 用大白话说，MCP 是什么？

您平时用的 AI 助手（比如 Claude、DeepSeek）很聪明，但它有一个天生短板：**不知道今天的行情**。您问它"现在硫磺多少钱一吨"，它只能凭训练时的旧知识猜。

**MCP（Model Context Protocol）就是给 AI 装上的"数据插座"**——一个业界通用的标准协议。我们做了一个 MCP 服务器，相当于在 AI 助手和我们的系统之间架了一座桥：

```
您在 AI 里提问："最近硫磺价格走势怎么样？"
        ↓
AI 自动调用我们的 MCP 工具
        ↓
MCP 服务器带着密钥去我们系统取实时数据
        ↓
AI 拿到真实数据后，用自然语言回答您
```

整个过程您什么都不用做，就像平时聊天一样提问，AI 自己会去查数据。

#### 一个真实的使用场景

> **您问**："未来两周硫磺价格会怎么走？我库存还剩 5000 吨，要不要现在补货？"
>
> **AI 会自动做三件事**：
> 1. 调用价格预测工具，拿到模型预测的未来走势；
> 2. 调用知识图谱工具，查询当前影响价格的关键因素；
> 3. 综合分析后给您回答，附带采购建议。
>
> 以前这需要打开系统、翻好几个页面；现在一句话搞定。

#### 一共开放了 18 个工具，覆盖六大类

| 分类 | 工具 | 您能问的话 |
|------|------|-----------|
| **行情数据** | 价格查询、港口库存、市场新闻 | "最近一周华东液硫价格走势？""港口库存变化如何？""最近有什么利好利空消息？" |
| **价格预测** | ARIMA+XGBoost 预测、Transformer 预测、组合预测 | "未来两周价格怎么走？""用深度学习模型再预测一遍对比看看" |
| **预测评估** | 准确率指标查询 | "你们的预测模型历史表现怎么样？" |
| **多品种分析** | 品种列表、单品种分析、跨品种对比 | "尿素和甲醇现在什么行情？""几个原料品种放在一起对比一下" |
| **智能追踪** | 创建订阅、订阅管理、告警查询、服务状态 | "价格超过 1500 元/吨时通知我""我都订阅了哪些提醒？" |
| **知识与报告** | 知识图谱查询、生成报告、应用案例 | "中东局势对硫磺价格有什么影响？""帮我生成一份市场追踪报告" |

#### 怎么接入？

通过 **Claude Desktop** 接入，只需一次简单配置：

1. 在 Claude Desktop 的开发者设置里添加一段配置（指向我们的 MCP 程序，填上您的 API 密钥）；
2. 重启 Claude Desktop，输入框旁出现工具图标即接入成功；
3. 之后正常聊天提问即可，AI 自动调用全部 18 个工具。

详细的图文接入教程见在线文档：**https://weikang.mintlify.app/guide/mcp**

#### 安全吗？

- 每一次数据请求都需要 **API Key 认证**，没有密钥拿不到数据；
- 密钥在网页控制台自助申请、可随时停用；
- MCP 服务器支持 Docker 部署，可以放在云端，也可以放在**您自己的服务器**上。

#### 这件事的意义

一句话：**以前是"人适应系统"——您得学会用我们的网站；现在是"系统适应人"——您用最习惯的聊天方式，数据和分析自动送上门。**

这也是行业趋势：未来企业软件的入口会越来越多地变成 AI 对话，我们提前把这条路铺好了。

### 4. 预测更透明、更强：准确率看板 + 新模型

**准确率看板**
- 新增了预测准确率页面，把每一次预测值和实际价格的偏差摆出来给您看（MAPE、MAE 等专业指标全部可视化）；

**新预测模型**
- 在原有的 ARIMA + XGBoost 混合模型之外，新增了 **Transformer 深度学习预测通道**（和 ChatGPT 同源的技术架构，擅长捕捉长周期的价格规律）；
- 多个模型互相验证，预测结果更稳健。

## 常见问题 Q&A（备用）

**Q：价格数据多久更新一次？**
A：系统有定时任务自动采集行情数据，追踪系统最高按小时巡检。

**Q：预测能保证准吗？**
A：任何预测都有不确定性，我们不承诺"一定准"。我们做的是把准确率指标完全公开在看板上，您可以自己查看模型的历史表现，用数据判断可信度。

**Q：接 API 复杂吗？**
A：不复杂。网页上的 API 控制台可以直接申请密钥、在线调试，文档站有快速开始指南，开发人员一般当天就能跑通。

**Q：MCP 和 API 有什么区别？我该用哪个？**
A：API 是给"系统"用的——您的 ERP、数据中台通过程序调用；MCP 是给"AI 助手"用的——您在 Claude、DeepSeek 里聊天时 AI 自动调用。业务人员日常用 MCP 更方便，系统集成用 API。

**Q：用 MCP 需要懂技术吗？**
A：不需要。在 Claude Desktop 里做一次简单配置即可，我们的在线文档（https://weikang.mintlify.app/guide/mcp）有零基础分步教程，也可以由我们协助完成。

**Q：我们数据不能出内网，怎么办？**
A：预测服务支持 Docker 私有化部署，可以整套部署在您的内网服务器上。
